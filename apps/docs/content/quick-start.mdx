    resolver CDNs (not a raw `unpkg.com/.../dist/index.js` URL) to resolve internal

## 2. Import the stylesheet

`@tederash/components` ships a precompiled stylesheet with all of the
adaptive styling — touch target sizing, high-contrast borders, focus rings,
font scale, reduced motion. Import it once, near your app's other global CSS:

```ts
import "@tederash/components/style.css";
```

Skip this and the components still *behave* correctly (ARIA, announcements,
confirmations, keyboard handling), but every profile will look identical to
Standard because none of the adaptive styling has anywhere to render from.
No Tailwind setup is required — the stylesheet is self-contained and safe to
import alongside your own Tailwind build if you have one.

## 3. Wrap your application

```tsx
// app/providers.tsx
import { TederashProvider } from "@tederash/react";
import { DEFAULT_TEDERASH_PROFILE } from "@tederash/core";

export function Providers({ children }: { children: React.ReactNode }) {
  return (
    <TederashProvider defaultProfile={DEFAULT_TEDERASH_PROFILE}>
      {children}
    </TederashProvider>
  );
}
```

The provider:

- Instantiates the accessibility runtime (or accepts an existing one via `runtime`).
- Subscribes the tree with `useSyncExternalStore`: no unnecessary re-renders.
- Applies resolved CSS variables and data attributes to `document.documentElement`.
- Persists user preferences to `localStorage` automatically (pass `persistence="none"` to disable).

## 4. Use adaptive components

```tsx
import { TederashButton, TederashForm, TederashInput } from "@tederash/components";

export function SignupForm() {
  return (
    <TederashForm onSubmit={submit} successAnnouncement="Account created.">
      <TederashInput
        label="Email address"
        type="email"
        description="Enter the email address associated with your account."
        required
      />
      <TederashButton type="submit" variant="primary">
        Submit application
      </TederashButton>
    </TederashForm>
  );
}
```

## 5. Switch profiles at runtime

```tsx
"use client";
import { useTederash, LOW_VISION_PRESET } from "@tederash/react";
import { useLocale } from "@tederash/react";

function ProfileControls() {
  const { setProfile } = useTederash();
  const { locale, setLocale, t } = useLocale();

  return (
    <>
      <button onClick={() => setProfile(LOW_VISION_PRESET)}>
        Low vision preferences
      </button>
      <button onClick={() => setLocale("am")}>
        {locale === "am" ? t("labels.help") : "አማርኛ"}
      </button>
    </>
  );
}
```

No page reload is required. Every subscribed component updates immediately.

## 6. Verify the adaptation

Switching to `LOW_VISION_PRESET` produces, without any application code changes:

- `--a11y-font-scale: 1.35` and larger target heights on the root element
- `data-a11y-high-contrast="true"` and a high-visibility focus ring
- Adaptive component sizing, contrast, and instructions

Inspect the live state in the playground (`pnpm dev`) via the runtime inspector and the axe-core audit drawer.
